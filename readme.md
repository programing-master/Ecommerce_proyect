🛍️ Online Shop - Tienda E-commerce Moderna
Una tienda online moderna y responsive construida con Next.js 16, TypeScript y Tailwind CSS. Incluye funcionalidades completas de carrito de compras, filtrado de productos y diseño UI/UX optimizado.

✨ Características Principales
🎯 Funcionalidades Implementadas
✅ Sistema de Carrito Completo - Agregar, eliminar y actualizar cantidades

✅ Filtrado Avanzado - Por categoría, precio, rating y más

✅ Búsqueda en Tiempo Real - En productos, descripciones y categorías

✅ Diseño 100% Responsive - Optimizado para móvil, tablet y desktop

✅ Interfaz Moderna - Con animaciones y efectos visuales

✅ Gestión de Estado - Context API para estado global del carrito

🛒 Módulo de Carrito
Agregar productos con incremento automático

Eliminar items individualmente o vaciar carrito

Actualizar cantidades con límite de stock

Cálculos automáticos - Subtotal, envío, impuestos y total

Opciones de envío - Estándar, Express y Recogida

Indicadores visuales - Productos en carrito, stock bajo, etc.

🏷️ Filtros y Ordenamiento
Búsqueda por texto en múltiples campos

Filtro por categorías (selección múltiple)

Rango de precios con slider interactivo

Rating mínimo (0, 3+, 4+, 4.5+)

Filtros rápidos - Solo en stock, en oferta, destacados

Ordenamiento - Precio, rating, nombre, más nuevo

🚀 Tecnologías Utilizadas
Next.js 16 - Framework React con App Router

TypeScript - Tipado estático para mayor seguridad

Tailwind CSS - Framework CSS utility-first

React Icons - Librería de iconos

Context API - Gestión de estado global

React Hooks - useState, useEffect, useMemo, etc.
